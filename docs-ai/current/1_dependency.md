# SAF dependency inventory

## Scope and evidence

This inventory covers the formal SAF 2.0.0 release target with configuration schema 2, handler protocol 3/config support 2, and runtime storage under `.agents/`. Single-read byte snapshots, atomic commit receipts, protected ancestor checks, and lexical/parsed JSON-object validation use existing Git/PowerShell/.NET capabilities without a new package, runtime, compressor, or parser. Release and lock schemas remain 1. Evidence: `SAF.config.json`, its minimal consumer template, `scripts/init.ps1`, BAT entry points, `scripts/origin.ps1`, `scripts/local.ps1`, `scripts/saf-core.ps1`, `scripts/publish-saf.ps1`, fixture source, and CI declarations.

There are no package-manager manifests, application projects, NuGet/npm packages, project references, fonts/icons, databases, or deployed application services. SAF uses existing tooling and built-in .NET libraries; no third-party PowerShell modules, Pester package, external compressor, global CLI, service, or model-engine adapter is installed. Skills require an existing Agent capable of reading/executing their instructions; SAF does not provision one.
